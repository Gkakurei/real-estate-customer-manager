# CustomerSystem （26.09）

不動産営業向けの顧客管理（追客）アプリです。

紙で管理していた顧客の追客記録をデジタル化し、
情報共有や業務効率の向上につなげたいと考え、開発しました。

仕事で顧客の追客状況を紙に記録していたため、もっと簡単に記録・確認・共有できるようにしたいと思い、開発しました。

## 機能
- 顧客情報の登録・一覧表示（日付確認可能）
- 顧客情報の編集・削除
- CSVファイルへのデータ保存

## 使用技術
- Java
- Java Swing
- CSV

## 動作確認
- JARファイルからの起動
- 顧客情報の登録・保存
- アプリ終了後、再起動してもデータが残ることを確認
- 仮想顧客データでテスト

## 実行方法

Javaがインストールされている環境で、以下のコマンドを実行してください。

```bash
java -jar CustomerSystem.jar
```
